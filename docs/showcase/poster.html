How a plan is made

Four agents, one typed response

1

Calorie expenditure

A gradient-boosted model trained on 750,000 Kaggle rows predicts exercise calories, which feed a daily budget and the meal's target.

Exercise model R² 0.996
2

Meal recommendation

Allergy, diet and health filters run first, then local vector RAG retrieves from 34 tested recipes and rescales portions.

Works with no LLM key
3

Nutrition verification

Each ingredient is checked against USDA FoodData Central, with FatSecret and local tables as cached fallbacks.

Estimates are labelled
4

Supermarket

Ingredients map to grocery products with an estimated cost and a tick-off list, marked as estimates.
